# USYD requisite extraction, 2026-10-30

Source: the per-stream "Unit of study table" pages of the current Bachelor of
Engineering (Honours) handbook, under

    https://www.sydney.edu.au/handbooks/engineering/engineering-honours/streams/<stream>/unit-of-study-table.html

Collected to fill the gap recorded in Section 4.2.4: CUSP supplies the degree
structure but no per-unit requisites, and the handbook-table step that supplied
them for Software Engineering was never run for the other degrees.

## Notation

    P=(A,B)(C,D)        two AND-separated groups, each a disjunction
    P=(A,B,[(C)(D)])    an alternative that is itself a conjunction
    P={36cp of 3000}    a requirement that is not a unit code
    MATH1X61            a wildcard as printed by the handbook, NOT expanded here

Codes are preserved exactly as the page prints them. Nothing is paraphrased,
no equivalent is substituted and no wildcard is expanded, because the engine
needs the logical structure rather than a description of it.

## Civil: resolved, see the Civil section below

RESOLVED. The current Civil stream table was located and is included below. The
account that follows is kept because it records why the first Civil table found
was rejected, and the rejection turned out to be correct: the current page
agrees with the current Environmental page on all three disputed units.

The first Civil table found was at

    https://www.sydney.edu.au/handbooks/engineering/engineering_honours/civil/table.html

which is the 2024 handbook (published 2023-11-15, amended 2024-04-04), and it
disagrees with the current Environmental page on three shared units:

    CIVL2010   current: (MATH1061)(MATH1062)                                   2024: none
    CIVL2410   current: (CIVL1022,ENVE1001)(MATH1061)(MATH1062)(ENGG1810)      2024: none
    CIVL3614   current: (CIVL2611,AMME2261)                                    2024: (CIVL2611)(CIVL3612)

Mixing handbook years would put two different rule sets in one dataset, so that
table was discarded and the current one used instead.

Across all seven pages, 259 distinct unit codes were extracted and no unit's
prerequisite code structure differs between any two pages that list it. Six
units appear on two pages with differently punctuated brace annotations, for
instance "{WAM 70%}{36cp of ...}" against "{WAM 70%; 36cp of ...}", and in every
case the unit-code structure is the same.
